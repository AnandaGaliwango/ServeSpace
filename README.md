# Task Manager CRUD Application


## Technologies

- React
- Vite
- Axios
- JSONPlaceholder API
- PostgreSQL


## Features

- Fetch data from API
- Create tasks
- Update tasks
- Delete tasks
- Search functionality
- Pagination
- Local storage caching
- Responsive design


## API

https://jsonplaceholder.typicode.com


## Queue System

Implemented PostgreSQL job queue using:

- Row level locking
- FOR UPDATE SKIP LOCKED
- Priority processing


## Running Project

Install dependencies:

npm install


Run:

npm run dev
